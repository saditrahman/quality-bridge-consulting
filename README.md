# Quality Bridge Consulting website

Upload all files in this folder together, preserving their filenames.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `reach.html` — Reach
- `why-us.html` — Why Us
- `contact.html` — Contact

Shared presentation and interaction files are `styles.css` and `script.js`.

## Before production launch

1. Upload the `assets` folder together with every page and shared file.
2. Connect the contact form to an email, CRM, or form-handling service.
3. Submit `https://qualitybridgeconsultancy.com/sitemap.xml` to Google Search Console after deployment.

The canonical URLs, social sharing image metadata, logo, robots file and sitemap are configured for `https://qualitybridgeconsultancy.com/`.
